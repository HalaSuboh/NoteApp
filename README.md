# MyNotes — Android Note App

**ENCS5150 – Advanced Computer Systems Engineering Laboratory**  
Electrical and Computer Engineering Department  
Birzeit University | Summer Course 2026

## About the Project

MyNotes is an Android application developed as a university project. It allows multiple users to create accounts and securely manage their personal notes.

Users can create, view, edit, delete, search, and favorite their notes through a simple and user-friendly interface.

## Features

### User Authentication
- User registration and sign-in using email and password.
- Input validation for registration fields.
- Remember Me functionality using SharedPreferences.
- User profile editing.
- Logout functionality.

### Notes Management
- Create, view, edit, and delete notes.
- Store note titles, content, and creation dates.
- Display all notes in a dedicated section.
- Mark notes as favorites and remove them from favorites.
- Send notes by email.

### Organization and Search
- Search notes by title or content.
- Sort notes alphabetically or by creation date.
- Save sorting preferences using SharedPreferences.
- Categorize notes using tags and filter notes by category.

### User Interface
- Navigation Drawer for navigating between sections.
- Fragments for displaying note content.
- Favorite animations and visual indicators.
- A user-friendly interface for managing notes.

## Technologies Used

- **Language:** Java
- **Development Environment:** Android Studio
- **Database:** SQLite
- **User Preferences:** SharedPreferences
- **UI:** XML Layouts, Activities, and Fragments

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Wait for Gradle synchronization to complete.
4. Run the application on an Android emulator or a connected device.
